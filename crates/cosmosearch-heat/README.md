# cosmosearch-heat

Usage tracking for cosmosearch, which decides where vectors pay off.

A plug-in for [cosmosearch](https://github.com/cosmobuild/cosmosearch). To use it, turn on the `heat` feature of [`cosmosearch`](https://crates.io/crates/cosmosearch); its types are in `cosmosearch::heat`.
