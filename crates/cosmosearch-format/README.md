# cosmosearch-format

The file table and chunk records of the cosmosearch index.

Part of [cosmosearch](https://github.com/cosmobuild/cosmosearch). The on-disk tables of a cosmosearch index: the file table and the chunk records, in Parquet.

Used by the indexer and the reader. Most programs should depend on [`cosmosearch`](https://crates.io/crates/cosmosearch) instead.
