# cosmosearch-extract-csv

CSV extractor for cosmosearch.

A plug-in for [cosmosearch](https://github.com/cosmobuild/cosmosearch). To use it, turn on the `csv` feature of [`cosmosearch`](https://crates.io/crates/cosmosearch); its types are in `cosmosearch::extract`.
