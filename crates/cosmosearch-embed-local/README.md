# cosmosearch-embed-local

Local CPU embeddings for cosmosearch, using candle.

A plug-in for [cosmosearch](https://github.com/cosmobuild/cosmosearch). To use it, turn on the `embed-local` feature of [`cosmosearch`](https://crates.io/crates/cosmosearch); its types are in `cosmosearch::embed_local`.

You provide the model files.
