# cosmosearch-indexer

Indexing for cosmosearch: file changes, indexing jobs and promotion.

Part of [cosmosearch](https://github.com/cosmobuild/cosmosearch). Records file changes, plans and runs indexing jobs, and promotes or demotes shards. Most programs use it through [`cosmosearch`](https://crates.io/crates/cosmosearch) with the `indexer` feature, as `cosmosearch::index`.
