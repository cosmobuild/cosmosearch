# cosmosearch-lexical

BM25 keyword search for cosmosearch, over tantivy.

A plug-in for [cosmosearch](https://github.com/cosmobuild/cosmosearch). To use it, turn on the `lexical` feature of [`cosmosearch`](https://crates.io/crates/cosmosearch); its types are in `cosmosearch::lexical`.
