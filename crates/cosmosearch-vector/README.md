# cosmosearch-vector

Vector search for cosmosearch: an IVF index and an embedding store.

A plug-in for [cosmosearch](https://github.com/cosmobuild/cosmosearch). To use it, turn on the `vector` feature of [`cosmosearch`](https://crates.io/crates/cosmosearch); its types are in `cosmosearch::vector`.
